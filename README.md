Pick your favorite cellular automata pattern.

FractalVote presents four randomly selected patterns and lets you choose the one you like best. Each vote helps determine which patterns people prefer.

## How it works

1. Four cellular automata patterns are randomly selected.
2. The patterns are displayed side by side.
3. You pick your favorite.
4. Your vote is recorded anonymously.
5. A new round appears automatically.

## Features

- 3,420 unique cellular automata rules
- Anonymous voting
- One vote per session per round
- Randomized rounds
- Dark and light mode
- Responsive design
- Keyboard accessible
- No account required

## Technology

- HTML / CSS / JavaScript
- HTML Canvas for rendering patterns
- Supabase Edge Functions
- Supabase PostgreSQL
- Cloudflare Pages

## Privacy

FractalVote does not require an account, name, or email address.

A random anonymous session ID is stored in the browser to prevent the same session from voting multiple times in the same round.

## Status

FractalVote is currently in development.
